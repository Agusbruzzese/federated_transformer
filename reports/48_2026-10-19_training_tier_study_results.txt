SUMMARY
-------
Frozen decision rule output: "NO FILTER NEEDED (noisy events harmless)".
  - The deployment recipe S+F trained on ALL events (SNR >= 10) is
    EQUIVALENT to S+F trained on clean events only (SNR >= 20).
  - Nuisance gate: PASS.
Nuance, reported in full:
  - S+F loses a small but statistically clear amount on lobes when noisy
    events are added: -0.017 [-0.032, -0.003], inside the 0.04 margin.
  - For central and plain federated, adding noisy events changes nothing
    (-0.008, +0.000).
Clear secondary result: training on noisy events ONLY is clearly worse
(lobes -0.055 to -0.075 vs clean-only, INFERIOR for central and S+F).
Mixing clean events back in recovers all of it.
Data rule for the runbook:
  - sites may train on all events with SNR >= 10;
  - for the S+F recipe, SNR >= 20 is marginally better and is the
    preferred default;
  - never train on noisy events alone.

3. NOTE ON THE PRE-REGISTERED RULE (stated openly)
  Report 47's rule text lists two clauses that both match this result:
    - "EQUIVALENT ... without a gain, gate PASS -> NO FILTER NEEDED";
    - "the lobes CI entirely < 0 -> FILTER TO SNR >= 20".
  The frozen code checks the EQUIVALENT clause first and returned NO FILTER
  NEEDED. That is the pre-registered output and it is reported as such.
  But the lobes CI for S+F lies entirely below 0, a small real loss
  inside the margin. Both facts are reported. The practical recommendation
  (sec. 4) takes the more conservative reading for S+F only.

4. DATA RULE (for the runbook)
  - Central or plain federated training: use all events with SNR >= 10.
    It is equivalent to clean-only.
  - The S+F recipe (recommended deployment): train on SNR >= 20 by
    default. Adding noisy events is within the margin (equivalent) but
    costs about 0.017 lobes.
  - Never train on noisy events only: about 0.06-0.075 worse on lobes.
  - Score models with clean-event labels (report 46).
  - Noisy events do not introduce extra nuisance encoding (gate PASS).

5. LIMITS
  Fixed compute: T10 sees each event about half as often as T20 within the
  same budget. A larger budget could change the T10 result. Same days,
  same sensor. Probes are fitted on clean client events (the study
  protocol; identical for T20 and T10).
