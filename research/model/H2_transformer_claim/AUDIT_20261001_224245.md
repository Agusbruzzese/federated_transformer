# External audit: research/model/H2_transformer_claim

_20261001_224245 · served by claude-sonnet-5-5 · effort medium · 11640 in / 2278 out · ~$0.046_

## Verdict
ACCEPT WITH FIXES. As a pre-registration the design is mostly sound, but it has no brief of its own, several circularity and statistical problems, and undefined rules that must be fixed before any training.

## Issues

1. [MAJOR] PREREG, targets: The shape scores come from morph8 columns (`m8_dur10`, polarity, lobes, magnitude), which are computed on the 402-sample central crop of the same windows the models see. Per the brief the evaluation crop is 600 samples, but E's window is 1050 samples, and the 600-sample crop is never defined. RAW and PCA-64 therefore see a different span than the one the targets were computed on. The S4 magnitude target (<5 000 counts) is an amplitude target, which contradicts the stated "no amplitude/SNR target" lesson. RAW is max-normalised and so loses amplitude, which handicaps RAW and PCA on S4/S5. -> Define the crop exactly and state that all competitors use the same crop. Drop S4/S5 or report them separately, or give RAW and PCA an amplitude feature. Justify the 5 000-count threshold.

2. [MAJOR] PREREG, CNN oracle: The CNN's temperature is chosen per run on test scores. The TF has one fixed cell and no oracle. This is conservative for the H2 claim, but it inflates CNN variance and is selection on test data. Oracle selection is also made per run, which makes the paired differences non-comparable across runs. -> Report the CNN at each fixed T as well, and state that the oracle is applied after averaging over seeds, not per seed.

3. [MAJOR] PREREG, Decision rules: The 4/4 rule combined with Holm and the 0.02 margin is stated, but the bootstrap over only 4 runs has almost no resolution. A resample of 4 runs drawn with replacement can contain a single run, and the minimum p is bounded by the number of distinct run subsets. With 4 runs p<0.05 may be nearly unattainable or degenerate, and the block-level resampling treats within-run blocks as independent despite temporal autocorrelation. -> Compute the minimum achievable p, or replace it with an exact sign-flip or permutation test over runs. Report effect sizes with intervals. Define how Holm is applied across the 5 scores for each competitor (the family is unclear when there are 4 comparisons).

4. [MAJOR] PREREG, H4: The rule "is-0204 skill ≤ TF-init + 0.05" is undefined. "Across all runs" is ambiguous when each model is trained on 3 runs and the embeddings live in different spaces per fold. The date probe within the held-out run is mixed with run leakage. The "worse of LR and kNN" probes pick the maximum over two probes, which biases toward failure, and no null or shuffled baseline is given. The 0.03 limit conflicts with E's observed date leakage (0.024 for morph at SNR≥20), which sits right at the threshold. -> Specify the exact probe, fold and embedding for each leakage test, add a shuffled-label null, and justify the thresholds against morph8's own leakage.

5. [MAJOR] PREREG, Overall verdict: H1 and H3 alone give "Partly supported", yet the claim being tested is "better than the alternatives" — TF-init, PCA and RAW are not "the alternatives" in the claim's sense. The thresholds (≥4 of 5 with 0.02 margin) are applied to correlated scores. S1–S5 are highly dependent (S5 is a function of S1 and S4), so "≥3 of 5" is not 3 independent confirmations. -> Treat S5 as derived, or require the pass count among S1–S4. Define the verdict wording to avoid "Proven".

6. [MAJOR] PREREG, Pilot contamination: The H pilot on run 0218 was seen by the author, and 0218 is also reused for the galleries, the t-SNE map and the seed-7 query choices. The hyperparameters (lr 3e-4, T 0.1) were possibly chosen from the pilot. -> State how the cell was chosen, and say that 0218 results are not independent of the pilot. Report the 0218 fold separately.

7. [MINOR] PREREG, Training pool: The set of training events is not stated (SNR≥20 only? the "background pool" is undefined). The CNN is parameter-matched at about 211k vs 207k, but this does not equalise compute or the augmentations used. The run-0204 blip population and its high dropout rate (1.05 %) are not addressed, although run 0204 is both a train fold and a test fold. -> Specify the SNR tier and the augmentations, and report the 0204 fold with and without blips.

8. [MINOR] PREREG, Probe: 5-fold CV grouped by 30-min block within the run leaves adjacent blocks as near neighbours. Events that are one vehicle passing, or near-duplicates, may span blocks. The kNN k=15 and z-scoring are not applied to TF-init consistently across dimensions (the embedding dimension is not stated, and PCA-64 differs). -> Fix the embedding dimension, add a buffer between train and test folds, and state the seeds for the CV splits.

9. [MINOR] PREREG, Dry run: There are no numeric pass thresholds for the planted, noise and one-hot controls ("high", "≈0"). -> Give them numerically before running.

10. [MINOR] PREREG: Compute budget and fixed seeds are partly listed (60+20 trainings), but data seeds, the bootstrap seed 0 and the TSNE settings are not all fixed. No confidence levels per finding are promised, though the briefs require them.

4. Compute morph8's own leakage and the run/date probe nulls to justify the H4 limits.
