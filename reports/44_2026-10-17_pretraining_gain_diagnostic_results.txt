SUMMARY
-------
Pre-registered verdict:
  H-data    NOT supported
  H-lr      NOT supported
  H-client  SUPPORTED
Neither a clean server nor a re-tuned learning rate restores the gain.
On low-SNR clients, server pretraining gives no measurable benefit.
A descriptive finding qualifies this (section 4): on the low-SNR tier, the
server model ALONE, with no federated training at all, already scores as
high as every trained model. All good models sit at about the same level
(lobes 0.41-0.43). The test may therefore be measuring a ceiling set by
the noisy low-SNR labels, rather than a true absence of benefit. Section 5
gives a cheap test that separates the two.

4. DESCRIPTIVE: THE CEILING
  On the low-SNR tier, the server model alone (trained only on the 2
  server days) scores lobes 0.42-0.43, as high as plain federated (0.432)
  and above central (0.408). The whole spread of trained models is about
  0.03, against the margin of 0.04.
  Compare the clean tier (report 24):
    - server alone 0.555, F-nat 0.577, S+F 0.626 (spread 0.07);
    - untrained to trained gap 0.32, here only 0.12.
  So on noisy events, every reasonable model reaches the same measured
  level, and further training adds almost nothing measurable. Two
  readings remain:
    (A) GENUINE: with noisy client data, the federated model already
        learns everything the server knows, so pretraining adds
        nothing;
    (B) MEASUREMENT CEILING: low-SNR lobe/polarity labels (derived from
        the noisy waveforms themselves) are too noisy to reveal
        differences between good representations. The gain may exist but
        be invisible.
  The pre-registered verdict (H-client) cannot tell A from B.

5. RECOMMENDED NEXT STEP (scoring only; no training)
  Score the SAME low-SNR-trained models (F-nat, S+F, Sclean+F, S+F@lrT,
  C256, S0) with probes and labels from the CLEAN tier (SNR >= 20
  events), whose labels are reliable.
    - These models never saw any SNR >= 20 event, so there is no
      leakage.
    - If pretraining now shows a gain -> reading B: the gain exists and
      the noisy labels hid it.
    - If not -> reading A is confirmed.
  Cost: about 40 min of scoring; pre-register first (report 45).

6. CONSEQUENCES SO FAR
  - Recipe: on noisy data, if server pretraining is used, run it at lr
    3e-4 (1e-3 was the worst of the grid). It is never worse than plain
    federated.
  - Claim status: "server pretraining helps" holds on SNR >= 20 events;
    on low-SNR events no benefit is measurable. Section 5 tests whether
    that is a property of the method or of the measurement.
