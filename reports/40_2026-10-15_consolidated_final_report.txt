1. BOTTOM LINE
--------------------------------------------------------------------------------
  1. Federated training across 10 sites learns a representation EQUIVALENT
     to central training on the same data (pre-registered, 10 seeds,
     9 unseen days; report 24).
  2. Pretraining on the server's own data before federating HELPS (+0.049
     on lobe structure), making the federated model non-inferior to
     central training (report 24).
  3. That recipe runs as a real federated system that is proven to compute
     exactly the study's models, bit for bit:
       - on local processes;
       - in containers;
       - on Flower's current runtime;
       - with TLS + site authentication;
       - under real platform failures with exact recovery
     (reports 27, 29, 31, 32).
  4. Secure aggregation (SecAgg+) hides each site's update from the
     server. It leaves learning EQUIVALENT to plain training (report 36).
  5. Site-level differential privacy is implemented exactly but is NOT
     usable with 10 sites. Every meaningful privacy level destroys the
     model (report 37).
  6. Release test: the full stack in 11 containers over emulated WAN
     links passed every pre-registered criterion: bit-identical model, isolation, intruders refused, exact recovery (report 39). A defect in Flower's SecAgg+
     workflow (a failed round is silently skipped) was found and fixed
     (report 38).
  RECOMMENDED DEPLOYMENT: S+F recipe, Flower runtime, TLS + site
  authentication, SecAgg+ with the round-continuity guard
  (fl_system5/app). No differential privacy.

2. THE SCIENTIFIC RESULT (reports 08-24)
--------------------------------------------------------------------------------
  Data:
    - 4 375 vehicle events (SNR >= 20), one TMR sensor, 14 winter days
      (Feb 2025); 12 s waveforms at 50 Hz, max-normalised.
    - No labels and no video exist, so quality is measured with
      morphology probes (lobe count, polarity; duration secondary).
  Design:
    - 3-fold cross-fitting over 9 evaluation days; per fold exactly 10
      day-clients; server days Feb 18 + 20; tuning day Feb 10.
    - Equal budget of 2.56 M training examples; equal tuning budget.
    - 10 seeds x 3 folds per arm.
    - Protocol frozen by sha256 before training (report 17).
    - Planted controls proved the decision rules could pass and fail
      (report 19).
    - Every number was recomputed independently (900/900 identical;
      report 23).

    arm       lobes   polarity   meaning
    C256      0.600   0.914      central, the pre-registered reference
    F-nat     0.577   0.904      FedAvg, 10 day-clients
    S+F       0.626   0.908      server pretraining, then FedAvg  <- deployed
    C64       0.635   0.916      central, batch 64 (descriptive)
    untrained 0.276   0.756

  Results:
    F-nat vs C256: lobes -0.023 [-0.034, -0.012], polarity -0.010
      [-0.015, -0.004], margins +-0.04 / +-0.02 -> EQUIVALENT. The nuisance
      gate passes: federated stores no more day-specific information than
      central.
    S+F vs F-nat: +0.049 [+0.034, +0.063] lobes (p = 3e-6); vs
      equal-compute FedAvg +0.038 -> HELPS. S+F vs C256: NON-INFERIOR
      (+0.026 lobes).
  Caveat: central with batch 64 is +0.035 above the batch-256 reference.
    Plain FedAvg is about one margin below that variant (descriptive).
  Scope:
    - one sensor and site, 14 winter days, morphology probes only;
    - exploratory with respect to a dataset used in earlier phases.

4. SECURITY AND PRIVACY (reports 30, 33-37)
--------------------------------------------------------------------------------
  SecAgg+ (M3):
    - decoded sum within the theoretical quantisation bound (error
      2.3e-7 <= 3.96e-7);
    - the vector the server receives from a site has |correlation|
      <= 0.005 with that site's true update.
    - Learning: the pre-set per-seed criterion (|diff| <= 0.01) FAILED
      for 1 of 3 seeds (report 33). The pre-registered 10-seed
      equivalence test then found EQUIVALENT (unseen seeds 3-9: lobes
      +0.0005 [-0.014, +0.015], polarity -0.002 [-0.007, +0.003]). The
      quantisation acts like a change of seed, not a bias (report 36).
    - Cost: +29 % round time; upload twice the model size (64-bit masked
      integers).
  Differential privacy (M4, site level, report 37):
    - Mechanism: clip, add distributed Gaussian noise before SecAgg+, and
      account exactly with mu-GDP.
    - Unit tests and an exact simulator (bit-identical to the real system)
      pass.
    - No noise level keeps the model equivalent to plain training.
    - From epsilon <= 1311 the model ends worse than the server-pretrained
      model it started from; at epsilon 6.6, lobes 0.235 vs 0.676 plain.
    - The cause is structural: with 10 sites the noise must hide about
      17 % of each round's update.
    - Record-level DP would need a different loss; it is a separate study.

6. DEFECTS FOUND, AND WHY THEY MATTER
--------------------------------------------------------------------------------
  Every defect was found by a test before it could affect a result:
    - study: sequential instead of averaged clients, a shared noise pool
      across clients, a gate-averaging bug, code/protocol mismatches
      (report 24 sec. 1);
    - system: FedAvg aliasing, object arrays in provisioning, server hang
      after a refused round, stale SuperNodes, lost replies in the
      SuperLink store (reports 26, 29, 31);
    - release: Flower's SecAgg+ workflow skips a round whose unmasking
      failed, then waits forever for the dead site (report 38). Fixed by
      the round-continuity guard. Any deployment of SecAgg+ on Flower 1.39
      should include it.

--------------------------------------------------------------------------------
7. WHAT IS NOT PROVEN (read before relying on this)
--------------------------------------------------------------------------------
  - Generalisation beyond one sensor, one site and 14 winter days, and to
    vehicle classes (no labels exist).
  - Real separate machines: the WAN was emulated (tc netem) on one host
    with one GPU. Round times on separate machines will differ; traffic
    per site will not.
  - A formal privacy bound on the final model (site-level DP is unusable
    here; record-level DP not done).
  - Behaviour with sites joining or leaving between rounds: the strict
    all-sites rule is deliberate, and SecAgg+'s dropout recovery is not
    used.
  - SecAgg+ equivalence was tested on fold 0 only (the plain system's
    exactness covers all folds).
